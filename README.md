LoiNhoiSideMod

Đây là mod hỗ trợ dành cho máy chủ Loi Nhoi.
- Tùy chỉnh phím sử dụng kỹ năng
Bấm ESC → Tùy chọn → Điều khiển, tìm mục của LoiNhoiSideMod.
Gán nút thi triển kỹ năng theo phong cách của bạn.

- Gộp thông báo
Những thông báo từ hệ thống sẽ được gộp lại, giữ khung chat sạch sẽ.
Ngoài ra, còn có thể tắt/mở các kênh trò chuyên như hình.

- Chỉ số trang bị
Khi xem trang bị trong túi đồ, giữ Shift để hiển thị thêm thông tin về Tẩy Luyện và Hồn đã ép. Chỉ số từ Tẩy Luyện và Hồn sẽ được tách riêng khỏi Chỉ số gốc, Cường hóa và Biến thể.

- Yêu cầu
Minecraft Java 1.21.4
Fabric Loader
Fabric API dành cho Minecraft 1.21.4

- Cách cài đặt
1. Cài Fabric Loader cho Minecraft 1.21.4.
2. Tải Fabric API tương ứng và LoiNhoiSideMod.
3. Bỏ cả hai file .jar vào thư mục mods trong thư mục Minecraft.
Nếu gặp lỗi hoặc chưa biết cách cài, có thể nhờ Staff và người chơi khác hỗ trợ trong [Discord Loi Nhoi](https://discord.loinhoi.net/).
